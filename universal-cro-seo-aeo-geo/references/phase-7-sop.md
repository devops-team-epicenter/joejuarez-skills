# PHASE 7 — ONGOING SOP (monthly, ~3–4 hours)

Block 1 (20m) — GSC + Bing review; flag every regression.

Block 2 (20m) — Position tracking via Semrush/Ahrefs IF the owner has
access (Phase 0.0 manifest); otherwise GSC query data only. Refresh
competitor list quarterly.

Block 3 (40m) — 20-prompt AI-citation audit across all 5 answer
engines; log to the admin panel tracker.
Execution mode: same Live-Query Capability Check as Phase 0.2. If the
LLM cannot query the engines itself, it emits the monthly Worksheet
(pre-filled with the 20 prompts) and waits for the human to paste
results into the Phase 5.3 tracker. The block is not "done" until the
tracker has real data for that month — do not silently skip.

Block 4 (30m) — On-site freshness: refresh dates + stats on
top-traffic pages; add 1 new case study every 60 days; update
llms-full.txt when content changes.

Block 5 (30m) — Off-site: 1 GBP post (or site-type equivalent),
review responses, 2 HARO pitches, NAP audit on top-10 citations.
Reconcile with the Off-Site Action Packet checklist from Phase 6.7:
any NEEDS_HELP row is triaged here.

Block 6 (20m) — CRO tests review: open the Phase 5.8 Test Log. For
every RUNNING test, confirm it hasn't crossed the min sample size /
duration threshold prematurely. Ship any WINNER_* variants that have
cleared guardrail-metric checks. Retire any INCONCLUSIVE tests and add
their learning to the decision column. Queue the next 1–2 tests from
the Phase 0.8 CRITICAL/HIGH backlog (or DIRECTIONAL batch per 3.7.7).

Block 7 (15m) — UX evidence pass: review the month's session-replay
sample (20 sessions on the top conversion path); log rage clicks,
dead clicks, and form abandonment into the friction queue.

Quarterly: Core Web Vitals re-run on top templates; refresh comparison
pages if a new competitor entered the SERP; review all failing
findings in the SEO panel; re-check the 3.7.7 low-traffic branch;
re-run the 0.7.2 design-token drift check.

Annual: refresh testimonials, rotate glossary, rebuild keyword map
from a fresh SERP scrape, refresh OG images.
